# TOP SECRET AI — запуск на Windows

## 1. Встанови Python

Потрібен Python 3.11 або новіший. Під час встановлення увімкни `Add Python to PATH`.

## 2. Завантаж SAIT

GitHub: https://github.com/tangar19901990/SAIT

Натисни `Code` → `Download ZIP` і розпакуй архів, наприклад у `C:\SAIT`.

## 3. Запуск

Відкрий папку `SAIT` і двічі натисни:

`run_sait.bat`

Скрипт сам створить `.venv`, встановить залежності та Chromium для Playwright.

## 4. API-ключ

Для справжнього AI потрібен API-ключ у змінній середовища `OPENAI_API_KEY`. Не вставляй ключ у GitHub і не публікуй його в чаті.

На першому етапі launcher перевіряє локальну оболонку. Після підключення реального provider агент зможе виконувати інструменти.

## Важливо

Не видаляй `.venv`, якщо не хочеш повторно встановлювати залежності. Робочу папку агента можна змінити через `SAIT_WORKSPACE`.

# TOP SECRET AI — запуск на Windows

## 1. Что нужно

- Windows 10/11
- Python 3.11+ с опцией **Add Python to PATH**
- OpenAI API key

## 2. Подготовка

1. Скачай репозиторий как ZIP.
2. Распакуй его в отдельную папку.
3. Скопируй `.env.example` в `.env`.
4. Открой `.env` Блокнотом.
5. Вставь ключ после `OPENAI_API_KEY=`.
6. Сохрани файл.

Никогда не отправляй `.env` в GitHub и никому не показывай API key.

## 3. Запуск

Дважды нажми `run_sait.bat`.

При первом запуске Windows установит Python-зависимости и Chromium. Это может занять несколько минут.

## 4. Первый тест

Когда появится `YOU >`, напиши:

`Створи файл test.html з текстом TOP SECRET AI`

Для выхода напиши `exit`.

## Если Python не найден

Установи Python 3.11+ з python.org та під час встановлення увімкни **Add Python to PATH**, потім запусти `run_sait.bat` ще раз.

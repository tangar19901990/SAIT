# TOP SECRET AI — запуск на Windows

## Що потрібно

- Windows 10/11
- Python 3.11+
- хоча б один API-ключ: Gemini, Claude, OpenAI, Groq або OpenRouter

## Підготовка

1. Скачай репозиторій як ZIP і розпакуй у нову папку.
2. Скопіюй `.env.example` у `.env`.
3. Відкрий `.env` Блокнотом.
4. Встав хоча б один свій API-ключ.
5. Збережи `.env`.

**Не надсилай `.env` нікому і не завантажуй його в GitHub.**

## Запуск

Двічі натисни `run_sait.bat`.

При першому запуску SAIT створить `.venv`, встановить залежності та Chromium. Наступні запуски не повинні повторювати встановлення.

Коли з'явиться:

`YOU >`

введи:

`/providers`

Потім:

`/claude`

або:

`/gemini`

Для списку команд:

`/help`

## Перший браузерний тест

Після вибору Claude або Gemini введи:

`Використай браузер. Відкрий Google і скажи мені назву сторінки.`

## Якщо Python не знайдений

Встанови Python 3.11+ з python.org та увімкни **Add Python to PATH**, після чого запусти `run_sait.bat` ще раз.
